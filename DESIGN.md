# Design

Texas Krystal's site is plain, confident and professional, with bold slab headings and a few Texas accents.

## Color

| Token | Value | Use |
|---|---|---|
| `--ink` | #12263F | Headings, strong rules, closing band |
| `--text-secondary` | #3B4F68 | Body copy on white |
| `--text-muted` | #55677E | Small print |
| `--bluebonnet` | #1F4690 | Buttons and links |
| `--brick` | #A63A24 | Star, short heading rule, step numbers, focus ring |
| `--bg-surface` | #F4F6F8 | Quiet panels |
| `--border-glass` | #D9DEE5 | Hairlines |

Use brick sparingly. Do not use the state flag, seal or official marks.

## Type

- Headings: Zilla Slab 700.
- Body and controls: Source Sans 3.

## Components

- Sections are separated by rules, not shadows or glass.
- Buttons are 4px-radius blocks, at least 46px tall.
- The page header has one short brick rule under the headline.
- Do not use gradient text, labels above headings, emoji icons or scroll-reveal effects.
